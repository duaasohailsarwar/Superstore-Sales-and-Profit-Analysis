# Superstore-Sales-and-Profit-Analysis

## Overview
This project explores the Superstore Sales Dataset to uncover key insights about sales performance, discount strategies, regional profitability and customer behavior and translate those findings into actionable business insights.

## Tools Used
- **Excel & Power Query** - Data cleaning and transformation
- **MySQL** - KPI calculations and analytical queries
- **Power BI** - Data modeling (Star Schema) and interactive dashboards

## Methodology
1. Cleaned data in Excel, created derived columns (profit margin, shipping days)
2. Designed 30+ KPIs across 5 business objectives
3. Executed SQL queries for sales, profit, discount, regional, and customer analysis
4. Built Star Schema data model in Power BI with fact and dimension tables
5. Created 5 interactive dashboards analyzing performance across categories, regions, and segments
6. Conducted root cause analysis and developed data-driven recommendations
